# E-Commerce TechStore - Proyecto de Ejemplo para Git & GitHub

Este proyecto es una plantilla básica de E-commerce desarrollada en HTML, CSS y JavaScript vainilla, pensada para ser utilizada como material educativo en talleres prácticos de Git y GitHub.

## 📁 Estructura del Proyecto

```text
mi-ecommerce-github/
├── index.html        # Estructura principal y HTML semántico
├── css/
│   └── style.css     # Estilos responsivos de las cards, layout y carrito
├── js/
│   └── app.js        # Lógica de renderizado de productos e interactividad del carrito
└── README.md         # Documentación del proyecto
```

## 🚀 Ejercicios Sugeridos para el Taller

1. **Clonar / Crear Repositorio**: `git init` o `git clone`.
2. **Crear una rama (Feature Branch)**: `git checkout -b feature/nuevo-producto`.
3. **Modificar Productos**: Agregar un 7mo producto en el arreglo `productos` dentro de `js/app.js`.
4. **Commit & Push**: Subir los cambios a GitHub mediante Pull Request.
5. **Publicar en GitHub Pages**: Activar la pestaña Pages desde la configuración del repositorio para publicar la tienda en vivo.
